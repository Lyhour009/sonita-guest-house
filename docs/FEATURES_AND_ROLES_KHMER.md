| | |
|:---:|---|

| 📅 | ការស្នាក់នៅរយៈពេលខ្លី (short-stay) និងរយៈពេលវែង (long-stay) |
| 🧾 | ការចេញវិក្កយបត្រ (Invoice) និងគ្រប់គ្រងការទូទាត់ប្រាក់ |
| 🧹 | ការគ្រប់គ្រងការសម្អាតបន្ទប់ និងការជួសជុល |
| 🔔 | ការជូនដំណឹងក្នុងកម្មវិធី និងតាមអ៊ីមែល |
| 📊 | Dashboard ផ្សេងគ្នាទៅតាមតួនាទីនីមួយៗ |

## 👥 ២. តួនាទីអ្នកប្រើប្រាស់ (User Roles)

ប្រព័ន្ធមានតួនាទី **៤ប្រភេទ** ហើយអ្នកប្រើម្នាក់ៗមានតួនាទីតែមួយប៉ុណ្ណោះ។

> [!IMPORTANT]
> ការចូលប្រើទំព័រ ឬធ្វើសកម្មភាពនីមួយៗ ត្រូវបានត្រួតពិនិត្យពីខាង **Server** (មិនមែនគ្រាន់តែលាក់នៅលើអេក្រង់ទេ)
> ដូច្នេះអ្នកប្រើម្នាក់មិនអាចចូលទំព័ររបស់តួនាទីផ្សេងបានទេ ទោះបីលោកអ្នកសាកសាកល្បង URL ក៏ដោយ។

| | តួនាទី | ជាអ្នកណា |
|:---:|---|---|
| 👑 | **Admin** (អ្នកគ្រប់គ្រង) | ម្ចាស់ ឬអ្នកគ្រប់គ្រង Guest House — មានសិទ្ធិគ្រប់យ៉ាង |
| 🛎️ | **Receptionist** (បុគ្គលិកទទួលភ្ញៀវ) | បុគ្គលិកខាងមុខការិយាល័យ — ធ្វើការកក់បន្ទប់ ចូល/ចេញ និងទទួលការទូទាត់ |
| 🧹 | **Housekeeping** (បុគ្គលិកសម្អាត) | បុគ្គលិកសម្អាតបន្ទប់ និងធ្វើការជួសជុលដែលបានចាត់តាំង |
| 🧳 | **Guest** (ភ្ញៀវ) | អតិថិជនដែលចូលមើលបន្ទប់ កក់បន្ទប់ បង់ប្រាក់ និងស្នើសុំជួសជុល |

## 🧳 ៣. មុខងារសម្រាប់ភ្ញៀវ (Guest)

នេះជាតួនាទីលំនាំដើមសម្រាប់អ្នកណាដែលចុះឈ្មោះថ្មី។

<details open>
<summary><b>🔍 រកមើលបន្ទប់ (Browse Rooms)</b></summary>

មើលបញ្ជីបន្ទប់បានដោយមិនចាំបាច់ចូលគណនី អាចត្រងតាមប្រភេទស្នាក់នៅ (ខ្លី/វែង) និងកាលបរិច្ឆេទ។ ទំព័រលម្អិត
បន្ទប់មានរូបភាព តម្លៃ សម្ភារៈប្រើប្រាស់ និង **ប្រតិទិនកាលបរិច្ឆេទទំនេរ** ដែលបង្ហាញថ្ងៃណាដែលមានគេកក់រួច
(រហូតដល់ ១២ខែទៅមុខ)។ កាតបន្ទប់ និងទំព័រលម្អិតបន្ទប់ក៏បង្ហាញ **ការវាយតម្លៃជាមធ្យម** និងមតិយោបល់ថ្មីៗ
ផងដែរ បើបន្ទប់នោះមានគេវាយតម្លៃរួច (មើលផ្នែក "ការវាយតម្លៃ" ខាងក្រោម)។
</details>

<details open>
<summary><b>🛏️ កក់បន្ទប់ (Book a Room)</b></summary>

ស្នើសុំកក់បន្ទប់ ស្នាក់នៅរយៈពេលខ្លី (ថ្ងៃចូល/ថ្ងៃចេញ) ឬរយៈពេលវែង (ថ្ងៃចូល ជាមួយថ្ងៃចេញជាជម្រើស)
អាចបញ្ចូល **កូដបញ្ចុះតម្លៃ** ផងដែរបើមាន។ ការកក់ថ្មីនឹងមានស្ថានភាព `pending` (កំពុងរង់ចាំ) រហូតទាល់តែ
បុគ្គលិកបញ្ជាក់។
</details>

<details open>
<summary><b>📋 ការកក់របស់ខ្ញុំ (My Reservations)</b></summary>

មើលការកក់ទាំងអស់ និងស្ថានភាពបច្ចុប្បន្ន អាចលុបចោលការកក់ដែលនៅតែក្នុងស្ថានភាព `pending`។
</details>

<details open>
<summary><b>⏳ ចូលរួមក្នុងបញ្ជីរង់ចាំ (Join the Waitlist)</b></summary>

បើការស្វែងរកនៅទំព័រដើមរកមិនឃើញបន្ទប់ទំនេរតាមកាលបរិច្ឆេទដែលចង់បាន ភ្ញៀវអាចបញ្ចូលអ៊ីមែល
(និងលេខទូរស័ព្ទបើចង់) ដើម្បីទទួលការជូនដំណឹងពេលមានបន្ទប់ទំនេរ។
</details>

<details open>
<summary><b>⭐ សរសេរការវាយតម្លៃ (Leave a Review)</b></summary>

បន្ទាប់ពីការកក់ស្នាក់នៅរយៈពេលខ្លីមួយបានចេញរួច (`checked_out`) ភ្ញៀវនឹងឃើញការណែនាំនៅលើ Dashboard
ឲ្យវាយតម្លៃការស្នាក់នៅ (១ដល់៥ផ្កាយ) ព្រមទាំងសរសេរមតិយោបល់ — ម្តងគត់ក្នុងមួយការស្នាក់នៅ។
</details>

<details open>
<summary><b>🧾 វិក្កយបត្ររបស់ខ្ញុំ (My Invoices)</b></summary>

មើលវិក្កយបត្រទាំងអស់ (វិក្កយបត្រស្នាក់នៅខ្លីត្រូវបានបង្កើតដោយស្វ័យប្រវត្តិពេលចេញ រីឯវិក្កយបត្រស្នាក់នៅវែង
បង្កើតជារៀងរាល់ខែដោយ Admin) មើលចំនួនប្រាក់នៅជំពាក់ និង **ទាញយក PDF** បាន។
</details>

<details open>
<summary><b>💳 ការទូទាត់របស់ខ្ញុំ (My Payments)</b></summary>

ដាក់ស្នើការទូទាត់ប្រាក់ (សាច់ប្រាក់ / ផ្ទេរប្រាក់ធនាគារ / QR) ភ្ជាប់ជាមួយវិក្កយបត្រ អាចភ្ជាប់រូបភាព
ភស្តុតាងបានផងដែរ ហើយតាមដានថាតើត្រូវបានបញ្ជាក់ដោយបុគ្គលិកឬនៅ។
</details>

<details open>
<summary><b>🔧 ស្នើសុំជួសជុល (Maintenance Requests)</b></summary>

រាយការណ៍បញ្ហាក្នុងបន្ទប់ (ចំណងជើង ការពិពណ៌នា កម្រិតអាទិភាព) និងតាមដានស្ថានភាព
(កំពុងរង់ចាំ → កំពុងធ្វើ → ជួសរួច)។
</details>

<details open>
<summary><b>🔔 ការជូនដំណឹង (Notifications)</b></summary>

មានក្រុមរូបកណ្តឹងក្នុងកម្មវិធី ជាមួយអ៊ីមែលរាល់ពេលមានព្រឹត្តិការណ៍សំខាន់ (ការកក់ត្រូវបានបញ្ជាក់ វិក្កយបត្រថ្មី
ការទូទាត់ត្រូវបានបញ្ជាក់ ការផ្លាស់ប្តូរស្ថានភាពជួសជុល)។
</details>

<details open>
<summary><b>📊 Dashboard និង ⚙️ គណនី (Account)</b></summary>

**Dashboard** — ទិដ្ឋភាពរួមនៃការកក់បច្ចុប្បន្ន វិក្កយបត្រចុងក្រោយ និងការជូនដំណឹងថ្មីៗ។

**គណនី** — កែប្រែប្រវត្តិរូប ប្តូរពាក្យសម្ងាត់ ការផ្ទៀងផ្ទាត់ ២ជាន់ (2FA) ការចូលគណនីតាម Passkey
ការប្តូររចនាប័ទ្ម (ភ្លឺ/ងងឹត/តាមប្រព័ន្ធ) និង **ការប្តូរភាសាខ្មែរ/អង់គ្លេស**។
</details>

## 🛎️ ៤. មុខងារសម្រាប់បុគ្គលិកទទួលភ្ញៀវ (Receptionist)

- **🖥️ Dashboard ខាងមុខការិយាល័យ** — មើលភ្ញៀវចូលថ្ងៃនេះ ភ្ញៀវចេញថ្ងៃនេះ និងក្រឡាបង្ហាញស្ថានភាពបន្ទប់
  ទាំងអស់ជាបន្តផ្ទាល់ (ទំនេរ / កំពុងស្នាក់ / បានកក់ / កំពុងសម្អាត / កំពុងជួសជុល)។
- **📅 ការកក់ (Reservations)** — បញ្ជាក់ការកក់ដែលកំពុងរង់ចាំ ធ្វើការចូល (Check-in) និងចេញ (Check-out)
  (ការចេញនឹងបង្កើតវិក្កយបត្រស្នាក់នៅខ្លីដោយស្វ័យប្រវត្តិ) ព្រមទាំងបង្កើត **ការកក់ដោយផ្ទាល់ (Walk-in)**
  សម្រាប់ភ្ញៀវដែលមកដល់ដោយផ្ទាល់ដោយមិនធ្លាប់កក់ជាមុន (អាចបញ្ចូលកូដបញ្ចុះតម្លៃផងដែរ)។ បញ្ជីការកក់
  បង្ហាញ **សញ្ញាសម្គាល់ភ្ញៀវត្រឡប់មកវិញ 🔁** សម្រាប់ភ្ញៀវដែលធ្លាប់ស្នាក់នៅចប់សព្វគ្រប់លើសពី ១លើក
  ដើម្បីឲ្យបុគ្គលិកស្គាល់ភ្ញៀវសមាមិត្ត។
- **💳 ការទូទាត់ (Payments)** — ពិនិត្យការទូទាត់ដែលភ្ញៀវបានដាក់ស្នើ (ជាមួយរូបភាពភស្តុតាងបើមាន)
  និងបញ្ជាក់ ឬបដិសេធ — ការបញ្ជាក់នឹងធ្វើឲ្យស្ថានភាពវិក្កយបត្រ (បង់រួច/បង់ខ្លះ/មិនទាន់បង់) ប្តូរដោយស្វ័យប្រវត្តិ។
- ✅ មានមុខងារគណនីដូចអ្នកប្រើទាំងអស់ (ប្រវត្តិរូប សុវត្ថិភាព រចនាប័ទ្ម ភាសា)។

## 🧹 ៥. មុខងារសម្រាប់បុគ្គលិកសម្អាត (Housekeeping)

- **🛏️ ក្តារស្ថានភាពបន្ទប់ (Room Status Board)** — មើលថាបន្ទប់ណាត្រូវការសម្អាត (ពេលភ្ញៀវចេញ
  បន្ទប់នឹងប្តូរទៅស្ថានភាព `cleaning` ដោយស្វ័យប្រវត្តិ) និងសម្គាល់ថាបានសម្អាតរួច ដែលនឹងប្តូរបន្ទប់
  ត្រឡប់ទៅ `available` វិញ។
- **🔧 ការស្នើសុំជួសជុល (Maintenance)** — មើលការជួសជុលដែលបានចាត់តាំងឲ្យខ្លួន និងកែប្រែស្ថានភាព
  (កំពុងធ្វើ → ជួសរួច)។ ពេលការជួសជុលមួយត្រូវបានដោះស្រាយរួច ហើយបន្ទប់នោះស្ថិតក្នុងស្ថានភាព
  `maintenance` បន្ទប់នឹងត្រឡប់ទៅ `available` វិញ។
- ✅ មានមុខងារគណនីដូចអ្នកប្រើទាំងអស់។

## 👑 ៦. មុខងារសម្រាប់អ្នកគ្រប់គ្រង (Admin)

Admin មានសិទ្ធិធ្វើអ្វីៗគ្រប់យ៉ាងដែល Receptionist និង Housekeeping អាចធ្វើបាន បូកនឹង៖

- **📊 Admin Dashboard** — អត្រាកាន់កាប់បន្ទប់ (ខ្លី/វែង/ទំនេរ) ចំណូលខែនេះ ចំនួនវិក្កយបត្រនៅជំពាក់
  ចំនួនការជួសជុលនៅសល់ **ក្រាបបង្ហាញនិន្នាការចំណូល ១៤ថ្ងៃ** និង **ក្រាបបំបែកអត្រាកាន់កាប់បន្ទប់**។
- **🏠 គ្រប់គ្រងបន្ទប់ (Room Management)** — បង្កើត/កែប្រែ/លុបបន្ទប់ (លេខបន្ទប់ ប្រភេទ របៀបជួល
  តម្លៃ ចំណុះ សម្ភារៈ ការពិពណ៌នា) និងគ្រប់គ្រងរូបភាពរបស់បន្ទប់នីមួយៗ។
- **🧾 វិក្កយបត្រ (Invoices)** — មើលវិក្កយបត្រទាំងអស់របស់ភ្ញៀវគ្រប់រូប (ត្រងតាមស្ថានភាព) បង្កើត
  វិក្កយបត្រប្រចាំខែសម្រាប់ភ្ញៀវស្នាក់នៅវែងដោយដៃ (ដោយបញ្ចូលចំនួនអគ្គិសនី/ទឹក) និងទាញយក PDF។
- **🛎️ សេវាកម្មបន្ថែម (Services)** — គ្រប់គ្រងសេវាកម្មបន្ថែមដែលអាចគិតលុយភ្ញៀវ (ដូចជាអាហារពេលព្រឹក
  សេវាបោកគក់ ការទទួល-ដឹកជញ្ជូនអាកាសយានដ្ឋាន)។
- **👤 គណនីបុគ្គលិក (Staff Accounts)** — បង្កើត/កែប្រែគណនី Receptionist និង Housekeeping
  (ស្វែងរក/ត្រងតាមតួនាទី) ព្រមទាំងចាត់តាំងការជួសជុលឲ្យបុគ្គលិកសម្អាតជាក់លាក់ណាមួយ។
- **⚙️ ការកំណត់ (Settings)** — រូបិយប័ណ្ណ អត្រាពន្ធ ម៉ោងចូល/ចេញលំនាំដើម អត្រាគិតលុយអគ្គិសនី/ទឹក
  ថ្លៃពិន័យយឺត និងការណែនាំ/QR Code សម្រាប់ការទូទាត់ប្រាក់ដែលបង្ហាញដល់ភ្ញៀវ។

## ✨ ៧. មុខងារថ្មីៗដែលទើបបន្ថែម

<div align="center">

![New](https://img.shields.io/badge/🆕-6%20មុខងារថ្មី-ff69b4?style=for-the-badge)

ផ្នែកនេះជាមុខងារ **៦** ដែលបានបន្ថែមថ្មីៗ ដើម្បីធ្វើឲ្យប្រព័ន្ធពេញលេញ និងដូចប្រព័ន្ធគ្រប់គ្រង Guest House
ពិតប្រាកដកាន់តែច្រើន។

### ⭐ ៧.១ ការវាយតម្លៃ និងមតិយោបល់ភ្ញៀវ (Reviews & Ratings)

ភ្ញៀវអាចផ្តល់ការវាយតម្លៃ (**១ដល់៥ផ្កាយ**) ព្រមទាំងសរសេរមតិយោបល់ បន្ទាប់ពីបានស្នាក់នៅ **ស្នាក់នៅរយៈពេលខ្លី
ហើយបានចេញរួច (`checked_out`)** ប៉ុណ្ណោះ។ ភ្ញៀវម្នាក់អាចវាយតម្លៃការស្នាក់នៅម្តងម្នាក់តែម្តងគត់ (មិនអាចវាយតម្លៃ
ការកក់របស់អ្នកដទៃ ឬវាយតម្លៃម្តងទៀតលើការស្នាក់នៅដដែលបានទេ)។

- ពេលភ្ញៀវ Check-out រួច ប្រព័ន្ធនឹងផ្ញើការជូនដំណឹងសួរថា *"ការស្នាក់នៅរបស់អ្នកយ៉ាងម៉េចដែរ?"* ដើម្បីលើកទឹកចិត្ត
  ឲ្យវាយតម្លៃ។
- ការវាយតម្លៃជាមធ្យម និងចំនួនការវាយតម្លៃសរុប បង្ហាញនៅលើកាតបន្ទប់ (ទំព័រដើម) និងទំព័រលម្អិតបន្ទប់
  ជាមួយបញ្ជីមតិយោបល់ថ្មីៗ ៥ចុងក្រោយ (ឈ្មោះភ្ញៀវ ផ្កាយ មតិយោបល់ និងកាលបរិច្ឆេទ)។

> [!TIP]
> **ប្រយោជន៍**៖ ជួយភ្ញៀវថ្មីមានទំនុកចិត្តក្នុងការសម្រេចចិត្តកក់បន្ទប់ ដូចជា Booking.com ឬ Agoda ដែរ។

### ⏳ ៧.២ បញ្ជីរង់ចាំ (Waitlist)

ពេលភ្ញៀវស្វែងរកបន្ទប់ ប៉ុន្តែគ្មានបន្ទប់ណាទំនេរតាមកាលបរិច្ឆេទដែលចង់បាន ភ្ញៀវអាចបញ្ចូលអ៊ីមែល (និងលេខ
ទូរស័ព្ទបើចង់) ដើម្បីចុះឈ្មោះក្នុង **បញ្ជីរង់ចាំ**។

- Admin មានទំព័រគ្រប់គ្រងបញ្ជីរង់ចាំដាច់ដោយឡែក អាចមើលអ្នកកំពុងរង់ចាំទាំងអស់ (ស្វែងរកបានតាមអ៊ីមែល)។
- ពេលមានបន្ទប់ទំនេរសម្រាប់ភ្ញៀវណាម្នាក់ Admin អាចចុចប៊ូតុង **"ជូនដំណឹង"** ដើម្បីផ្ញើអ៊ីមែលទៅភ្ញៀវនោះ
  ដោយផ្ទាល់ថាឥឡូវនេះមានបន្ទប់ទំនេរហើយ (ជាការសម្រេចចិត្តរបស់មនុស្ស មិនមែនស្វ័យប្រវត្តិទាំងស្រុងទេ
  ព្រោះការផ្គូផ្គងកាលបរិច្ឆេទដោយស្វ័យប្រវត្តិស្មុគស្មាញ និងងាយមានកំហុស)។

> [!TIP]
> **ប្រយោជន៍**៖ មិនបាត់បង់ភ្ញៀវសក្តានុពលទេ ពេលបន្ទប់ពេញ។

### 🕵️ ៧.៣ កំណត់ត្រាសកម្មភាព (Activity Log / Audit Log)

ប្រព័ន្ធកត់ត្រាដោយស្វ័យប្រវត្តិរាល់សកម្មភាពសំខាន់ៗដែលបុគ្គលិក/Admin បានធ្វើ ដូចជា៖

| សកម្មភាព |
|---|
| 🏠 បង្កើត/កែប្រែ/លុបបន្ទប់ |
| 👤 បង្កើត/កែប្រែ/លុបគណនីបុគ្គលិក |
| 📅 ការបញ្ជាក់/ចូល/ចេញ/លុបចោលការកក់ |
| 💳 ការបញ្ជាក់ការទូទាត់ប្រាក់ |
| ⚙️ ការកែប្រែការកំណត់ប្រព័ន្ធ |

Admin មានទំព័រមួយសម្រាប់មើលកំណត់ត្រាទាំងអស់នេះ (អ្នកណាធ្វើ ធ្វើអ្វី ពេលណា) អាចស្វែងរក និងត្រង
តាមប្រភេទសកម្មភាព។

> [!TIP]
> **ប្រយោជន៍**៖ ប្រសិនបើមានបញ្ហា ឬចង់ដឹងថាអ្នកណាបានផ្លាស់ប្តូរអ្វី Admin អាចត្រឡប់ក្រោយមើលបាន
> ដូចជា "ប្រវត្តិសកម្មភាព" សុវត្ថិភាព (Accountability)។

### 📈 ៧.៤ របាយការណ៍ និងការទាញយកទិន្នន័យ (Admin Reports & Export)

Admin អាចជ្រើសរើសចន្លោះកាលបរិច្ឆេទណាមួយ (ឧទាហរណ៍ ១ខែ ឬ ១សប្តាហ៍) ដើម្បីមើលរបាយការណ៍សង្ខេប៖

- 💰 ចំណូលសរុប និងចំណូលបំបែកជាថ្ងៃៗ (ក្រាបនិន្នាការចំណូល)
- 📅 ចំនួនការកក់ថ្មីក្នុងចន្លោះពេលនោះ
- 🧾 ចំនួនវិក្កយបត្រនៅជំពាក់
- 🔧 ចំនួនការជួសជុលដែលដោះស្រាយរួច / នៅសល់ និងរយៈពេលជាមធ្យមក្នុងការដោះស្រាយ

លទ្ធផលអាច **ទាញយកជា CSV** 📄 (សម្រាប់បើកជាមួយ Excel) ឬ **ទាញយកជា PDF** 📕 ដើម្បីបោះពុម្ព ឬ
បញ្ជូនអ្នកវិនិយោគ។

> [!TIP]
> **ប្រយោជន៍**៖ ជួយ Admin វិភាគអាជីវកម្មដោយមិនចាំបាច់រាប់ដោយដៃ សមស្របសម្រាប់ធ្វើរបាយការណ៍
> ប្រចាំខែ ឬបង្ហាញអ្នកវិនិយោគ។

### 🏷️ ៧.៥ កូដបញ្ចុះតម្លៃ (Promo Codes)

Admin អាចបង្កើតកូដបញ្ចុះតម្លៃ (ឧទាហរណ៍ `SAVE20`) ដោយកំណត់៖

| ការកំណត់ | ជម្រើស |
|---|---|
| ប្រភេទបញ្ចុះតម្លៃ | **ភាគរយ (%)** ឬ **ចំនួនថេរ ($)** |
| កាលបរិច្ឆេទផុតកំណត់ | ជាជម្រើស |
| ចំនួនដងអតិបរមា | ជាជម្រើស — ទុកទទេគឺប្រើបានគ្មានកំណត់ |
| ស្ថានភាព | បើក ✅ / បិទ ❌ |

ភ្ញៀវ ឬបុគ្គលិកអាចបញ្ចូលកូដនេះនៅពេលកក់បន្ទប់ (ទាំងកក់ដោយខ្លួនឯង និងកក់ដោយផ្ទាល់ Walk-in)។ កូដនឹង
ត្រូវអនុវត្តលើ **ចំនួនប្រាក់មុនគិតពន្ធ** ពេលចេញវិក្កយបត្រ ហើយចំនួនបញ្ចុះតម្លៃមិនអាចលើសពីចំនួនប្រាក់មុន
គិតពន្ធនោះទេ (មិនអាចធ្វើឲ្យវិក្កយបត្រអវិជ្ជមានបានទេ)។

> [!WARNING]
> បើកូដផុតកំណត់ អសកម្ម ឬប្រើអស់ចំនួនកំណត់ហើយ ប្រព័ន្ធនឹងមិនអនុវត្តកូដនោះទេ ប៉ុន្តែការកក់នៅតែជោគជ័យ
> ធម្មតា (មិនរារាំងភ្ញៀវទេ)។

> [!TIP]
> **ប្រយោជន៍**៖ ជាឧបករណ៍ទីផ្សារសម្រាប់ទាក់ទាញភ្ញៀវថ្មី ឬលើកទឹកចិត្តការកក់ក្នុងរដូវកាលស្ងាត់។

### 🔁 ៧.៦ សញ្ញាសម្គាល់ភ្ញៀវចាស់ (Returning Guest Badge)

នៅលើទំព័រការគ្រប់គ្រងការកក់សម្រាប់បុគ្គលិក ប្រព័ន្ធនឹងបង្ហាញសញ្ញាសម្គាល់តូចមួយ (ដូចជា *"ភ្ញៀវត្រឡប់មកវិញ"*)
នៅជាប់ឈ្មោះភ្ញៀវ បើភ្ញៀវនោះធ្លាប់ស្នាក់នៅចប់សព្វគ្រប់ (`checked_out` ឬ `expired`) លើសពី **១លើក**
កន្លងមក។

> [!TIP]
> **ប្រយោជន៍**៖ ជួយបុគ្គលិកទទួលភ្ញៀវស្គាល់ភ្ញៀវសមាមិត្ត អាចផ្តល់សេវាកម្មពិសេស ឬការចាប់អារម្មណ៍
> បន្ថែមដល់ភ្ញៀវដែលធ្លាប់មកញឹកញាប់។

## 🌐 ៨. មុខងារទូទៅសម្រាប់គ្រប់តួនាទី (Cross-cutting Features)

- **🔔 ការជូនដំណឹង (Notifications)** — មានក្រុមរូបកណ្តឹងក្នុងកម្មវិធី ជាមួយអ៊ីមែលដែលផ្ញើដោយស្វ័យប្រវត្តិ
  រាល់ពេលមានអ្វីទាក់ទងនឹងគណនីនោះ (ការកក់/វិក្កយបត្រ/ការទូទាត់/ការជួសជុល)។
- **📕 ទាញយកវិក្កយបត្រជា PDF** — វិក្កយបត្រណាមួយអាចទាញយកជា PDF បាន (ភ្ញៀវទាញយកបានតែរបស់ខ្លួន
  ចំណែកបុគ្គលិក/Admin អាចទាញយករបស់អ្នកណាក៏បាន)។
- **🇰🇭🇬🇧 ការប្តូរភាសាខ្មែរ/អង់គ្លេស** — ប្តូរអត្ថបទគ្រប់ទំព័រទាំងអស់រវាងអង់គ្លេស និងខ្មែរបានភ្លាមៗ
  ត្រូវបានចងចាំតាមកម្មវិធីរុករក (Browser) និងផ្ទុកពុម្ពអក្សរខ្មែរដោយស្វ័យប្រវត្តិ។
- **🌓 ការប្តូររចនាប័ទ្មភ្លឺ/ងងឹត/តាមប្រព័ន្ធ** (Light/Dark/System Appearance)។
- **🔐 ការផ្ទៀងផ្ទាត់ ២ជាន់ (2FA) និង Passkey (WebAuthn)** — បន្ថែមពីលើការចូលគណនីធម្មតាតាមអ៊ីមែល
  និងពាក្យសម្ងាត់ ដើម្បីសុវត្ថិភាពខ្ពស់ជាង។
- **📂 ម៉ឺនុយចំហៀង (Sidebar) ដែលអាចបត់/ពន្លា** — ក្រុមម៉ឺនុយនីមួយៗ (ប្រតិបត្តិការ ហិរញ្ញវត្ថុ ការថែទាំ
  ការគ្រប់គ្រង) អាចបត់ ឬពន្លាបានដោយឯករាជ្យ ហើយប្រព័ន្ធចងចាំជម្រើសនោះទុកសម្រាប់លើកក្រោយ។
