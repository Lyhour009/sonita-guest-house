# Sonita Guest House — Features & User Roles

This document summarizes what the system does and what each user role can do. It reflects the
actual implemented functionality (routes, controllers, actions) as of this build, not the original
spec — see `docs/BUILD_SPEC_Sonita_Guest_House.md` for the original requirements the system was
built from.

## User roles

The system has four roles, stored on `users.role`:

| Role | Who they are |
|---|---|
| **Admin** | Property owner/manager — full access to everything. |
| **Receptionist** | Front-desk staff — handles reservations, check-in/out, payments. |
| **Housekeeping** | Cleaning staff — manages room cleaning and assigned maintenance work. |
| **Guest** | A customer — browses rooms, books stays, pays invoices, requests maintenance. |

A user has exactly one role. Access to every page and action is enforced server-side by role
(not just hidden in the UI), so a role can't reach another role's pages even by guessing a URL.

---

## Guest

The default role for anyone who registers. Represents a customer of the guest house.

- **Browse rooms** — public room listing (no login required), filterable by stay type
  (short-stay/long-stay) and date range, with a room detail page showing photos, pricing,
  amenities, and a live **availability calendar** (booked dates greyed out, 12 months ahead).
- **Book a room** — request a short-stay (check-in/check-out dates) or long-stay (move-in date,
  optional move-out date) reservation. Booking starts as `pending` until staff confirms it.
- **My Reservations** — view all their reservations and current status; cancel a still-pending
  reservation.
- **My Invoices** — view invoices generated for their stays (short-stay invoices are
  auto-generated at checkout; long-stay invoices are monthly, generated by an admin), see
  outstanding balance, and **download any invoice as a PDF**.
- **My Payments** — submit a payment (cash / bank transfer / QR) against an invoice, optionally
  attaching a proof image, and track whether it's pending or confirmed by staff.
- **Maintenance requests** — report an issue with their room (title, description, priority), and
  track its status (pending → in progress → resolved).
- **Notifications** — an in-app bell + a matching email for every account event: reservation
  confirmed, invoice issued, payment confirmed, maintenance status changes.
- **Dashboard** — at-a-glance view of current reservations, latest invoice, and recent
  notifications.
- **Account** — profile editing, password changes, two-factor authentication, passkey
  (WebAuthn) login, light/dark/system appearance, and a **Khmer/English language toggle**.

## Receptionist

Front-desk operations staff. Handles the reservation and payment lifecycle for guests physically
or remotely checking in/out.

- **Front desk dashboard** — today's arrivals, today's departures, and a live grid of every
  room's current status (available / occupied / reserved / cleaning / maintenance).
- **Reservations** — confirm pending guest bookings, check guests in, check them out (which
  auto-generates the short-stay invoice), and create a **walk-in booking** directly for a guest
  who shows up without an existing reservation.
- **Payments** — review guest-submitted payments (with proof image, if attached) and confirm or
  reject them; confirming updates the invoice's paid/partial/unpaid status automatically.
- Shares the same account features as any user (profile, security, appearance, language).

## Housekeeping

Cleaning and room-maintenance staff.

- **Room status board** — see which rooms need cleaning (after a guest checks out, the room
  flips to `cleaning`) and mark a room as cleaned, returning it to `available`.
- **Maintenance requests** — see maintenance requests assigned to them by an admin, and update
  status as they work (in progress → resolved). Resolving a request that had put the room into
  `maintenance` status returns the room to `available`.
- Shares the same account features as any user (profile, security, appearance, language).

## Admin

Full access — everything above, plus property/business management.

- **Everything Receptionist and Housekeeping can do**, in addition to:
- **Admin dashboard** — occupancy split (short-stay vs. long-stay vs. available), this month's
  confirmed revenue, outstanding invoice count, open maintenance count, a **14-day revenue trend
  chart**, and a **room occupancy breakdown chart**.
- **Room management** — create/edit/delete rooms (number, type, rental mode, pricing, capacity,
  amenities, description) and manage each room's photos.
- **Invoices** — view every invoice across all guests (filterable by status), manually generate a
  long-stay monthly invoice (with electricity/water meter readings), and download any invoice as
  a PDF.
- **Services** — manage the extra services guests can be billed for (e.g. breakfast, laundry,
  airport pickup).
- **Staff accounts** — create and edit receptionist/housekeeping accounts (search + filter by
  role); staff assignment of maintenance requests to a specific housekeeping account also happens
  here.
- **Settings** — currency, tax rate, default check-in/check-out times, electricity/water billing
  rates, late fee, and payment instructions/QR code shown to guests.

---

## Cross-cutting features (all roles)

- **Notifications** — in-app bell + matching email, sent automatically whenever something
  relevant happens to that user's account (reservation/invoice/payment/maintenance events).
- **PDF invoices** — any invoice can be downloaded as a formatted PDF (guests can only download
  their own; staff/admin can download any).
- **Khmer/English language toggle** — switches all page text between English and Khmer,
  persisted per-browser; a Khmer-capable font is loaded automatically when needed.
- **Light/dark/system appearance toggle.**
- **Two-factor authentication and passkey (WebAuthn) login**, in addition to standard
  email/password.
